# Design Principles

Due to this project's association with Microsoft, it is logical to use Microsoft's [Fluent 2 Design System](https://fluent2.microsoft.design/)

- During the design phase, the [Fluent 2 Web UI Kit](https://aka.ms/Fluent2Toolkits/Web/Figma) for Figma is used.
- During the development phase, the [Fluent UI React v9](https://react.fluentui.dev/) components can be used.
